# Nathan Felix Live Bridge

A lightweight, real-time SFTP/SSH file-sync pipeline and terminal GUI built in Python (CustomTkinter + Paramiko) as a standalone alternative to heavy IDE SSH extensions.

## Features
- **Real-Time SFTP File Sync:** Watches local project directories and pushes edits to remote Linux servers in under 50ms.
- **Standalone GUI & Terminal (elix_app.py, elix_terminal.py):** Integrated remote shell, permission fixer, and Laravel maintenance mode toggle.
- **Zero-Config Template:** Copy elix_config.example.json to elix_config.json and fill in your own server IP and SSH credentials.
